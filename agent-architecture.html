Architecture Thesis

从“听懂一句话”到“安全执行一个任务”

具身智能 Agent 的产品链路不能停在意图识别。它必须继续完成对象定位、安全门控、路线规划、执行状态管理、异常恢复和质量复盘。V5.3 把这些能力拆成可解释的模块边界。

输入自然语言、场景状态、历史上下文和用户修正。

Module Boundary

Agent 模块说明

每个模块都按输入、输出、风险和指标组织，方便面试讲解。

Intent Agent

识别用户是在移动物体、递送药盒、检查门口、机器人自主导航，还是对上一任务做修正。

输入：自然语言指令、上一轮任务状态
输出：intent、action、是否新任务
风险：把新任务误判成打断，导致旧物体泄漏

Grounding Agent

把“这个”“右边那个杯子”“老人旁边的东西”等表达绑定到场景对象和目标位置。

输入：对象候选、坐标、颜色、区域、选中上下文
输出：objectId、destinationId、候选分
指标：错拿率、澄清触发准确率

Safety Agent

判断药品、重物、老人照护、门口检查等任务是否需要确认、降级或人工接管。

输入：任务类型、对象风险、目标区域
输出：riskLevel、confirmation、handoff hint
指标：安全漏检率、确认成本

Planner Agent

生成从当前位置到对象、再到目标位置的路径，并处理“绕开椅子走”等空间约束。

输入：对象坐标、目标坐标、障碍物、约束
输出：waypoints、routeMode、risk markers
指标：路线可行性、安全分、绕行成本

Execution / Interruption Agent

管理执行状态，处理中途暂停、改目标、换对象、路径被挡和用户接管。

输入：执行进度、用户中途指令、感知事件
输出：暂停、重规划、继续、接管
风险：旧任务未取消导致带错物体移动

Evaluator Agent

把任务执行结果映射到评估集和 PM 证据卡，支撑复盘、回归和面试讲解。

输入：任务结果、路径报告、话术触发
输出：PASS/FAIL、证据、归因、下一步建议
指标：回归通过率、未覆盖场景数

我不是只做了一个可视化 Demo，而是在验证一个具身智能产品闭环：自然语言输入、场景 grounding、安全门控、路线规划、执行中打断和评估回归如何组成一个可交付的 Agent 任务系统。
