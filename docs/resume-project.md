# 简历项目经历：Voice-to-Action Agent

## 推荐版

**Voice-to-Action Agent 具身智能交互原型｜独立项目｜2026.05 - 至今**

**项目目标：** 面向家庭 / 服务机器人语音交互场景，独立设计并实现 Voice-to-Action Agent 本地原型，解决自然语言指令到可执行物理任务之间的对象指代、风险确认、路线规划与异常恢复问题，将用户“把杯子拿到厨房”“把药盒递给老人”“重箱子绕开椅子搬到门口”等口语化需求转化为结构化任务流，支撑从语音 / 多模态 Agent PM 向具身智能交互 PM 的作品集表达。

**Agent 任务流设计：** 基于多 Agent 编排拆解 Intent、Grounding、Safety、Planner、Recovery、Interruption、Evaluator 等模块，打通意图解析、场景对象定位、安全门控、路径生成、执行反馈与中途改口链路；支持“右边那个杯子”“老人旁边那个东西”“把这个拿到厨房台面”等多轮指代与场景上下文表达，并在前端可视化呈现任务理解、系统下一步决策、执行路径、风险提示和人工接管建议。

**质量评估闭环：** 围绕具身任务稳定性建立核心任务、执行中打断、语音反馈、路线质量和高级交互等评估集与测试计划页，覆盖歧义澄清、高风险确认、执行中改目标 / 换对象、动态环境感知、路线重规划、人工接管和话术触发等关键场景；沉淀 PRD、Agent 架构、指标体系、Case Study、版本演进和 Demo 脚本等作品集资产，核心任务评估保持 15/15 通过，并形成可面向产品面试讲解的质量治理证据链。
