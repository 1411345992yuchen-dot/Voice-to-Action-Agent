# Project Health

## Current State

V11 把项目从“作品集材料集合”收缩回 Voice-to-Action Agent 本体。当前主线只有三类入口：

1. `intro.html`：说明产品问题、主流程和非目标。
2. `index.html`：主产品 Demo，验证自然语言任务到物理执行流。
3. `test-plan.html`：核心验收页，证明关键行为可回归。

## Current Strengths

- 主 Demo 可本地运行，能展示从自然语言到机器人任务执行的闭环。
- Agent 编排链路清晰：Intent、Grounding、Safety、Planner、Evaluator。
- 支持对象澄清、安全确认、路线预览、执行中改口、异常恢复和运行日志。
- 核心验收默认聚焦 10 条主链路用例，目前 10/10 通过。
- 主 Demo 右侧新增四步核心流程条：理解、定位、安全门、执行。
- 任务状态新增用户化简报：系统判断、原因、用户动作。
- 新增聚焦版 `intro.html`，适合面试开场快速说明项目价值。

## Current Risks

- 场景仍是 2D 产品抽象，不是机器人 SDK 或真实仿真环境。
- 真实语音、Tool Calling 和 LLM 接入桥已作为历史实验保留，但不再是主路径。
- 路线专项复盘已收口为 4/4 通过，但仍不作为默认首屏主线，避免路线细项抢占 Voice-to-Action 主流程。
- 家庭场景视觉还可以继续打磨，但优先级低于主流程稳定性和讲解清晰度。

## V11 Scope Reset

- 新增 `intro.html` 作为唯一介绍页。
- 主 Demo 顶部导航只保留“产品介绍”和“核心验收”。
- `portfolio-hub.html` 改为跳转到 `intro.html` 的收缩说明页。
- 默认隐藏主 Demo 的高级评估按钮和底部大指标条，减少界面噪音。
- `README.md` 和 `docs/demo-links.md` 已改为聚焦版，只推荐主 Demo 与核心验收路线。

## V11.1 Interface Subtraction

- 主 Demo 默认界面继续做减法，只保留“一句话任务 / 家庭场景 / 任务状态”。
- 左栏撤下默认可见的完整语音 PM Demo、执行接管和指代对象折叠项。
- 语音确认、执行接管和指代对象改为按需展开：语音识别、澄清、确认或选中对象时才出现。
- 试跑场景从五个压缩为四个：日常执行、对象澄清、安全确认、执行改口。
- 右栏修复澄清/确认状态一致性：pending 写入后重新刷新状态卡，避免“需要澄清”时仍显示“已理解任务”。

## V11.2 Core Flow Evidence

- 主 Demo 的任务状态区新增四步核心流程条，默认展示理解、定位、安全门和执行的状态推进。
- `test-plan.html` 默认筛选改为“核心”，只展示 10 条主链路验收用例。
- 高级复盘沙盒默认折叠，避免测试页首屏被事故注入和全量细项占满。
- 全量回归仍可通过“全部 / 路线 / 高级交互”等筛选查看，用于后续专项复盘。

## V11.3 Status Language

- 主 Demo 在四步流程条下新增状态简报，统一输出“系统判断 / 原因 / 用户动作”。
- `buildDecisionSummary` 复用同一套状态简报，避免“下一步”和核心流程条文案不一致。
- 澄清、确认、接管、恢复、完成、执行中、已解析和待输入状态均有用户可理解文案。
- pending 状态下路线字段不再显示“已生成执行路径”，而是显示“待确认后执行”。
- 澄清和确认会写入时间线，避免 URL 试跑时底部仍停留在 Ready。

## V11.4-V11.6 Focused Core Polish

- V11.4 继续做右侧状态区减法：移除重复“下一步”卡片，只保留状态简报和任务事实，减少右侧信息抢占。
- V11.5 把语音入口从小图标改成明确的“语音”按钮，并默认露出语音确认区，让“先确认、再执行”的安全门控更清楚。
- V11.6 把路线深测改成路线专项复盘：`test-plan.html?filter=route` 可直达，支持 URL 记录筛选和用例，当前路线专项 4/4 通过。
- 绕行策略修正为用户约束优先：用户明确说“绕开椅子”时，即使默认路径没有贴近椅子，也生成可见绕行点和 `chair_avoided` 风险标记。

## Recommended Next

1. 继续强化语音确认区的真实体验，尤其是识别置信度、修正文本和确认后执行。
2. 在主 Demo 内增强对象澄清、安全确认、路线预览和执行反馈，不再横向新增材料页。
3. 把高级实验页移入更明确的 `archive` 或文档归档索引，避免未来继续发散。
