# Demo Video Outline

## Goal

Create a 2-3 minute portfolio video that shows the project as a product system, not only a coding demo.

## Structure

### 0:00-0:20 Project Positioning

Show `portfolio-hub.html`.

Narration: This is a Voice-to-Action Agent prototype for embodied interaction. It converts natural-language commands into executable robot task flows.

### 0:20-0:55 Main Demo

Show `index.html`.

Run a simple command such as: 把红色杯子拿到厨房台面.

Narration: The system parses the intent, grounds the object and destination, plans a route, moves the robot, carries the object, and updates task state.

### 0:55-1:25 Complex Interaction

Show `interview-demo.html`.

Narration: Real voice tasks include ambiguity, safety risks, mid-execution corrections, and recovery. These are packaged as repeatable demo flows.

### 1:25-1:55 Architecture

Show `agent-architecture.html`.

Narration: Each agent module has inputs, outputs, failure risks, and metrics. This keeps the system explainable and testable.

### 1:55-2:20 Quality Evidence

Show `test-plan.html` and `evidence-dashboard.html`.

Narration: The project includes regression cases, PM review, and evidence dashboards so product quality is visible.

### 2:20-2:30 Career Connection

Show `role-positioning.html`.

Narration: The project connects Huawei multi-agent workflow engineering experience to Agent PM, voice PM, and embodied intelligence PM roles.
