# Multimodal Grounding Prototype

## Why It Matters

具身智能交互里，用户很少会像数据库查询一样说清楚对象 ID。更常见的是：

- “右边那个杯子”
- “桌上那个红色物体”
- “老人旁边那个东西”
- “这个拿到厨房”

这些表达需要系统把语言、空间关系、视觉属性和上下文结合起来。V1.2 用轻量规则模拟这一层能力，为后续 VLM/真实视觉 grounding 留出产品结构。

## Scene Semantics

每个对象维护：

- `type`: cup, medicine, parcel, obstacle, box
- `color`: red, blue
- `zone`: 面向用户的区域描述
- `semanticZone`: 面向 Agent 的场景语义
- `aliases`: 别名和自然语言表达
- `x/y`: 2D 场景坐标
- `risk`: low, medium, high

## Grounding Strategy

Grounding Agent 会按以下线索打分：

1. 类型：杯子、箱子、药盒、包裹、障碍物。
2. 颜色：红色、蓝色。
3. 区域：桌上、门口、老人旁边、客厅左侧。
4. 空间：左边、右边、旁边、附近。
5. 上下文：用户在场景中点击过的对象。
6. 别名：对象的自然语言别名。

## Product Risks

- 错把障碍物当目标对象。
- 对“那个”这类指代词过度自信。
- 在高风险对象上绕过用户确认。
- 颜色、位置和对象类型发生冲突时无法解释。

## Current Guardrails

- 如果只有“杯子”且没有颜色/位置，系统进入澄清。
- 药品、重物、门口等场景触发安全确认。
- 椅子在搬运箱子任务里会作为避障约束，不作为目标对象。
- 所有 Agent 判断依据会显示在决策链里。
- 用户点击对象后，“这个/那个”会绑定到当前选中对象，作为短期交互上下文。

## Evaluation Cases

V1.2 的评估集覆盖：

- 低风险拿取放置
- 杯子歧义澄清
- 药品递送安全确认
- 门口包裹检查
- 箱子搬运与避障约束
- 红色物体视觉属性
- 右边杯子空间指代
- 老人旁边物品空间关系
- 已选中对象后的“这个”上下文指代
