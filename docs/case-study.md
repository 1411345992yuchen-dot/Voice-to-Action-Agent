# Case Study: Voice-to-Action Agent

## One-line Summary

一个面向具身智能交互的 Voice-to-Action Agent 原型：通过多 Agent 编排，把用户自然语言指令转化为可执行、安全、可恢复、可评估的机器人任务流。

## Problem

具身智能机器人要真正进入家庭、服务、工业等场景，用户不能只通过复杂 App 或遥控器操作。更自然的入口是语音和多模态交互，但语音交互的难点在于：用户说的是模糊意图，机器人执行的是物理动作，中间必须有澄清、安全和评估闭环。

## Product Hypothesis

如果一个 Agent 能把自然语言任务拆解为目标对象、动作、位置、约束、安全门控和执行计划，那么语音交互就能从“聊天入口”升级为“具身任务入口”。

## Solution

设计一个本地可运行原型：

- 用户输入自然语言任务
- 系统通过多个子 Agent 和语音反馈层生成可解释决策链
- 在对象不明确时要求澄清
- 在高风险任务前要求确认或接管
- 在执行中断时给出重规划、改目标、暂停等待或人工接管
- 在用户中途打断时支持暂停、改放目标位置、换目标对象和人工接管
- 在关键节点生成机器人语音反馈话术，覆盖理解、确认、执行、恢复和接管
- 将核心场景话术沉淀为语音交互脚本，展示状态反馈、风险表达和人机协作边界
- 将语音反馈纳入评估集，验证关键状态是否触发正确话术
- 将路线报告纳入评估集，验证路径分段、绕行点、风险标记和策略标签是否符合物理执行预期
- 在 2D 场景中模拟机器人执行
- 用指标面板和评估集验证行为质量

## Product Scope

### In Scope

- 语音/文本输入
- 2D 家庭/服务机器人场景
- 自然语言任务解析
- 多模态指代 grounding
- 安全确认
- 异常恢复
- 执行中用户打断/改口
- 语音反馈和对话脚本
- 评估集回归
- 语音反馈回归评估
- 路线质量回归评估

### Out of Scope

- 真实机器人控制
- ROS/ROS2 接入
- 真实摄像头/VLM
- 大模型 API 调用
- 复杂 3D 仿真

## Why This Matters For PM Transition

这个项目可以证明三类能力：

- Agent 产品能力：多 Agent 编排、任务流、指标和评估。
- 语音交互能力：从自然语言意图到行动计划。
- 具身智能理解：物理世界安全、对象定位、动作执行和异常兜底。

## Outcome

- 当前支持 15 条核心评估用例，15/15 通过。
- 支持执行中改口演示：原任务执行中可取消未完成动作并重建任务计划。
- 新增打断专项评估集，覆盖 7 条动态意图用例，当前 7/7 通过。
- 新增语音反馈评估集，覆盖 7 条话术触发用例，当前 7/7 通过。
- 新增路线质量评估集，覆盖 4 条路线报告用例，当前 4/4 通过。
- 新增 Grounding 证据面板和执行路径预览，展示对象候选分、路线分段、预计耗时和路径风险。
- 新增路线重规划能力，执行中说“绕开椅子走”会生成真实绕行点，并让机器人按路线段逐段移动。
- 新增测试计划页，合并 33 条用例并展示 expected vs actual、PASS/FAIL 和 PM 复盘口径。
- 新增版本演进页，将 V1.0-V2.4 串成产品问题、关键优化、PM 能力和证据链。
- 新增语音反馈模块和语音交互脚本，让 Demo 更贴近语音交互型具身智能产品。
- 形成完整作品集资产：Demo、PRD、架构、指标、评估集、Case Study、演示脚本、简历 bullet。
- 能支撑“语音/多模态 Agent PM -> 机器人交互 PM -> 具身智能 PM”的转型叙事。

## Resume Bullet

独立设计并实现 Voice-to-Action 具身智能交互 Agent 原型，面向家庭/服务机器人任务场景，将自然语言指令转化为可执行任务流，覆盖意图解析、对象定位、多轮澄清、安全确认、动作规划、异常兜底、路线质量评估与评估集回归，沉淀 PRD、Agent 架构图、交互原型和指标体系。
