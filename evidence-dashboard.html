Evidence Thesis

一个项目，四类证据

作品集最怕只有“我做了”。这个面板把项目转成四类可被追问的证据：功能证据、质量证据、产品证据、面试证据。

功能Agent 编排、语音确认、路线规划、异常恢复。
质量核心评估、打断评估、语音评估、路线评估、真实语音评估。
PMPRD、指标、决策日志、Case Study。
面试官可以追问的问题：
这个项目怎么证明你能做 Agent PM？怎么证明你理解语音交互？怎么证明你不是只会做工程实现？这个面板就是把这些问题对应到证据。

Evidence Categories

四类证据面板

功能证据

  • Intent / Grounding / Safety / Planner / Evaluator 多 Agent 编排。
  • Tool Calling Lab 把核心模块包装成可替换工具接口。
  • 支持“右边那个杯子”“老人旁边那个东西”等场景指代。
  • 高风险任务进入安全确认和人工接管。
  • 执行中支持暂停、改目标、换对象和路线重规划。

质量证据

  • 核心任务评估保持 15/15 通过。
  • 打断、语音反馈、路线质量、高级交互和语音交互均有专项用例。
  • 真实语音评估覆盖 ASR 置信度、人工修正、误触发阻止和确认后 Agent 解析。
  • Tool Calling 评估覆盖工具调用数量、执行门控、澄清/确认和阻止执行。
  • 测试计划页展示 expected vs actual 和 PM Review 归因。
  • Review Sandbox 能模拟错拿对象、安全漏检和旧任务泄漏。

PM 证据

  • README、PRD、Roadmap、Metrics、Case Study 已沉淀。
  • 版本演进页说明每个阶段对应的产品问题和能力变化。
  • 决策日志解释为什么选择 2D、为什么做门控、为什么做评估集。
  • 语音专项页把小爱拒识/误响应经验迁移到具身任务场景。

面试证据

  • 面试演示页提供四条黄金路径和可运行链接。
  • 一页式 Brief 可以直接转发给 HR / 面试官做异步评审。
  • 岗位讲法页为 Agent PM、语音 PM、具身 PM、AIOps PM 准备不同叙事。
  • Agent 架构页可解释模块边界、失败风险和评估指标。
  • 简历项目经历可以直接对应这些页面进行追问。
