Recommended Opening

一句话开场

我做的是一个 Voice-to-Action 具身智能交互 Agent 原型，重点不是聊天，而是把用户自然语言任务转成可执行、安全、可恢复、可评估的机器人任务流。这条链路和我现在做的多 Agent 告警工作流有连续性，只是从 AIOps 工作流迁移到了物理任务执行场景。

最推荐投递定位：
技术可信的 Agent / 语音交互 / 具身智能产品经理候选人。优势不是纯 UI 原型，而是能把复杂任务流拆成模块、状态、指标、风险和评估集。

Pre-flight Checklist

面试前检查清单

服务已启动确认 `http://localhost:8765/` 能打开，主 Demo 不要现场再找命令。
先演黄金路径优先讲日常递送、歧义澄清、老人药品确认、执行中改口。
不要陷入美术细节家庭场景只是 grounding 和执行状态载体，重点讲产品机制。
主动讲评估集强调 15/15 基线和测试计划页，体现 PM 的质量意识。
连回华为经历把 AIOps SOP 工作流经验迁移到具身任务流，不要讲成兴趣项目。
准备下一步下一阶段可接 LLM function calling、VLM grounding、语音真链路和机器人 SDK。
