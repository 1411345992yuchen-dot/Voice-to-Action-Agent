Integration Thesis

真实 LLM 接入不是替代门控，而是被门控约束

V10 的重点不是炫耀“接了一个模型”，而是把接入前必须想清楚的产品边界展示出来：密钥不能进浏览器，模型只能选择工具，最终动作必须经过 grounding、安全、路线和执行门控。

Proxy浏览器不持有 API Key，只调用本地后端代理。
Schema工具输入输出可审计，防止 prompt 直接越权执行。
Fallback代理失败时本地 Agent 仍能维持安全演示。
面试讲法：
我把 V10 做成“可接真实 LLM 的桥”，而不是直接把 API Key 写进前端。LLM 负责理解和组织工具调用，但物理动作仍由本地 Agent 的 grounding、安全、路线和 gate 约束。这样即使模型失败，也不会把风险带到执行层。
